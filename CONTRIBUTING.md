# Contributing

Thanks for improving the handbook! 🚀

## Adding a format

Add it to the catalog only when you can document:

- canonical name
- representation
- engineering domain
- purpose
- common use
- limitations or notes

## Documentation style

Prefer:

- short sections
- practical examples
- tables
- explicit trade-offs
- security notes where relevant

Avoid:

- unsupported claims
- vendor marketing language
- copying proprietary specifications
- pretending a format is universally best

## Pull request checklist

- [ ] Catalog entry added
- [ ] Extension/name checked
- [ ] Documentation updated where useful
- [ ] Validation script passes
- [ ] No secrets or private data included
- [ ] No generated junk committed
