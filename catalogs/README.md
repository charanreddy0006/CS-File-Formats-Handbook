# Catalogs

The catalog layer turns this repository from static documentation into a small **machine-readable knowledge base**.

## Files

| File | Purpose |
|---|---|
| `master-catalog.csv` | Human-friendly tabular catalog |
| `master-catalog.json` | Structured catalog |
| `extension-index.json` | Fast extension lookup |
| `format-families.json` | Grouping by engineering role |
| `mime-types.json` | Selected MIME type mapping |

The catalog is intentionally curated rather than pretending to be an exhaustive registry of every format ever created.
