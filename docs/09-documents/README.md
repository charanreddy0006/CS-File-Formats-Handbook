# 📚 Document Formats

| Format | Main use |
|---|---|
| `.txt` | plain text |
| `.md` | Markdown |
| `.rst` | reStructuredText |
| `.adoc` | AsciiDoc |
| `.tex` | LaTeX source |
| `.pdf` | fixed-layout document |
| `.docx` | Word document |
| `.odt` | OpenDocument text |
| `.rtf` | rich text |
| `.epub` | e-book |

## Markdown

Popular for:

- GitHub README files
- documentation
- notes
- static sites

## PDF

PDF is designed for consistent document presentation across systems.

A PDF can contain text, vector graphics, raster images, fonts, metadata, forms, and other objects.

## DOCX

DOCX is an Office Open XML document package, typically stored as a ZIP-based package containing XML and related resources.
