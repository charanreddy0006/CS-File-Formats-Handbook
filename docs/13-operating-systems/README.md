# 🖥️ Operating System Files

## Windows

```text
.exe
.dll
.sys
.msi
.bat
.cmd
.ps1
.reg
```

## Linux / Unix

Linux executables often have **no extension**.

Common artifacts:

```text
.so
.a
.service
.conf
.sh
```

ELF is a major executable/object format on Unix-like systems.

## macOS

```text
.app
.dmg
.pkg
.dylib
```

## Important concept

The operating system often identifies a file by metadata, permissions, executable headers, and content — not simply by extension.
