# 📱 Mobile Development Formats

## Android

```text
.apk   application package
.aab   Android App Bundle
.dex   Dalvik Executable
.aar   Android library
```

## iOS / Apple platforms

```text
.ipa
.app
.xcodeproj
.xcworkspace
```

## Package vs executable content

An APK/AAB is a package containing application resources and compiled artifacts.

DEX files contain bytecode used by the Android runtime ecosystem.

The extension describes the artifact role; the internal package structure determines what is actually inside.
