# 💻 Programming Language Files

## Source code

| Extension | Language / ecosystem | Role |
|---|---|---|
| `.c` | C | source |
| `.h` | C/C++ | header |
| `.cpp` | C++ | source |
| `.hpp` | C++ | header |
| `.java` | Java | source |
| `.kt` | Kotlin | source |
| `.cs` | C# | source |
| `.py` | Python | source |
| `.pyi` | Python | type stub |
| `.js` | JavaScript | source |
| `.ts` | TypeScript | source |
| `.jsx` | React/JS | JSX source |
| `.tsx` | React/TS | TSX source |
| `.go` | Go | source |
| `.rs` | Rust | source |
| `.rb` | Ruby | source |
| `.php` | PHP | source |
| `.swift` | Swift | source |
| `.dart` | Dart | source |
| `.r` | R | source |
| `.sql` | SQL | query/script |

## Intermediate and compiled files

```text
.java → .class → .jar
.c/.cpp → object files → executable
.py → .pyc
.cs → assembly (.dll/.exe)
```

## No-extension source ecosystems

Shell scripts frequently use no extension:

```text
build
deploy
install
```

Executable permissions and shebangs may determine how they run.
