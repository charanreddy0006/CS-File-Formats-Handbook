# 🌐 Web Development Formats

## Core

```text
.html   structure
.css    styling
.js     JavaScript
.ts     TypeScript
.jsx    React JSX
.tsx    React TypeScript JSX
```

## Styling ecosystems

```text
.scss
.sass
.less
```

These are commonly compiled into CSS.

## Modern web artifacts

```text
.wasm
.webmanifest
.map
```

### Source maps

A `.map` file connects generated/minified code back to source code for debugging.

### WebAssembly

`.wasm` is a binary instruction format designed for execution in WebAssembly environments.

## Frontend build output

A source project may contain:

```text
src/
package.json
tsconfig.json
vite.config.ts
dist/
```

The source files and generated deployment files serve different purposes.
