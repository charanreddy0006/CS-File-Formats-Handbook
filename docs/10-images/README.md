# 🖼️ Image Formats

## Raster

| Format | Typical strengths |
|---|---|
| JPEG | photographs, small size |
| PNG | lossless images, transparency |
| WebP | web-oriented compression |
| AVIF | modern efficient image compression |
| GIF | simple animation / limited-color images |
| TIFF | high-quality imaging workflows |
| BMP | simple uncompressed raster |

## Vector

```text
.svg
```

SVG describes graphics using XML-based vector structures.

## Selection

```text
Photo → JPEG / WebP / AVIF
Transparency → PNG / WebP / AVIF
Logo/icon → SVG
Professional imaging → TIFF
Simple animation → GIF / modern video alternatives
```

Do not select a format solely because its file size is smaller. Consider quality, browser/application support, editing workflow, and transparency requirements.
