```text
.mp4
.mkv
.webm

.avi
```

```text
H.264

```

## Audio

```text
.mp3
.wav
.flac
.aac
.ogg
.opus
.m4a
```

## Codec vs container

```text
movie.mp4
 ├── video codec
 ├── audio codec
 └── metadata
```

A `.mp4` file does not tell you every codec inside it.

## Lossless vs lossy

Lossless compression preserves the original information.

Lossy compression discards information to achieve smaller representations.

Examples:

```text
FLAC → lossless audio
JPEG → lossy image
MP3 → lossy audio
```
