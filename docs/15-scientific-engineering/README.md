# 🔬 Scientific and Engineering Formats

| Format | Typical domain |
|---|---|
| `.mat` | MATLAB |
| `.h5` / `.hdf5` | hierarchical scientific data |
| `.nc` | NetCDF |
| `.fits` | astronomy |
| `.grib` | meteorological data |
| `.vtk` | scientific visualization |
| `.las` | LiDAR |
| `.dcm` | DICOM medical imaging |

These formats often support:

- metadata
- multidimensional arrays
- scientific units
- timestamps
- coordinate systems
- large datasets

Scientific formats are frequently optimized around domain-specific access patterns rather than general-purpose application storage.
