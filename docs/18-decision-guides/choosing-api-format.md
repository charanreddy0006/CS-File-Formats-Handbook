# Choosing an API Data Format

## JSON

Best known for:

- browser APIs
- REST APIs
- human-readable payloads
- broad language support

## XML

Useful where:

- established schemas matter
- legacy enterprise integrations exist
- document-oriented standards require it

## Protobuf

Useful for:

- strongly defined schemas
- efficient binary communication
- RPC systems
- generated clients

## GraphQL

GraphQL is an API query language and protocol ecosystem rather than simply a file extension.

## Rule of thumb

Choose based on:

```text
clients
schema requirements
payload size
streaming
versioning
tooling
organizational standards
```
