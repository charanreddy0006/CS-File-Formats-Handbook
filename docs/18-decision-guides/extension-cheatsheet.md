# Extension Cheat Sheet

```text
.py          Python
.ipynb       Jupyter Notebook
.sql         SQL
.json        JSON
.yaml/.yml   YAML
.toml        TOML
.csv         Comma-separated values
.jsonl       JSON Lines
.parquet     Columnar analytics
.avro        Schema-oriented serialization
.sqlite3     SQLite database
.md          Markdown
.pdf         PDF
.docx        Word document
.png         PNG image
.jpg         JPEG image
.svg         SVG vector
.webp        Web image
.mp4         MP4 container
.mkv         Matroska container
.mp3         MPEG audio
.flac        FLAC audio
.zip         ZIP archive
.tar         TAR archive
.gz          GZIP compression
.exe         Windows executable
.dll         Windows library
.so          Shared object
.apk         Android package
.ipa         iOS package
.onnx        ONNX model
.safetensors Tensor weights
.gguf        GGUF model file
.tf          Terraform
.env         Environment configuration
.pem         PEM-encoded security material
```

This is intentionally a quick index; consult the domain guides for deeper context.
