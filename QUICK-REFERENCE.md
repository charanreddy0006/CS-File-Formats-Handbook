# ⚡ Quick Reference

## Most important categories

```text
Source code       → .py .java .cpp .js .ts .go .rs
Config            → .json .yaml .yml .toml .ini .env
Data              → .csv .jsonl .parquet .avro .orc
Database          → .sql .sqlite .db
AI/ML             → .pt .pth .onnx .safetensors .gguf
Web               → .html .css .js .wasm
Docs              → .md .pdf .docx .tex
Images            → .png .jpg .svg .webp .avif
Media             → .mp4 .mkv .wav .flac .mp3
Archives          → .zip .tar .gz .7z .xz
Security          → .pem .crt .csr .p12 .pfx
Cloud/DevOps      → Dockerfile .tf .yml .yaml
Systems           → .exe .dll .so .dylib .deb .rpm
Mobile            → .apk .aab .dex .ipa
Scientific        → .h5 .hdf5 .nc .fits .mat
GIS/3D            → .geojson .shp .obj .stl .gltf .glb
```

## Remember

```text
extension ≠ format
format ≠ MIME type
container ≠ codec
archive ≠ compression
serialization ≠ compression
database dump ≠ database
model file ≠ model system
```
